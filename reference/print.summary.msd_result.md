# Print method for summary.msd_result

Produces nicely formatted output similar to summary.lm, designed for
applied social scientists.

## Usage

``` r
# S3 method for class 'summary.msd_result'
print(x, digits = 4, ...)
```

## Arguments

- x:

  A summary.msd_result object

- digits:

  Number of significant digits to display (default 4)

- ...:

  Additional arguments (ignored)

## Value

Invisibly returns x
